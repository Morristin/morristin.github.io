# Dark Reader 配置指南

## 使用个性化配色方案

### 开启配色方案功能

许多系统美化都要求选定一种特定且统一的配色方案。然而很少有人知晓 Dark Reader 本身提供配色方案选项，允许用户更改注入的 CSS 颜色代码。

为了开启配色方案功能，你需要按照如下步骤进行操作：

1. 在插件菜单栏中单击插件图标，此时会弹出司空见惯的 Dark Reader 插件选项页。
2. 通过选项页上方菜单栏导航到 More 并单击下方「All Settings」按钮。
3. 在打开的 Dark Reader 设置标签页中，通过左侧侧边栏导航到 Advanced ，单击「Dev Tools」。此时应该会弹出标题为 Dark Reader Developer Tools 的新窗口。
4. 在新窗口中通过左侧标签栏导航到 Advanced，点击「Enable design prototype」按钮。

此时，重复第一步，你理应发现插件选项页使用了全新的设计。接着进行如下步骤：

5. 在选项页中央附近的位置找到「See all options」按钮并点击。
6. 在所进入的下一层级中央附近的位置找到「Colors」按钮并点击，展开颜色相关选项。
7. 寻找到最下方的「Color Scheme」选项，从下拉菜单中选择你希望应用的配色方案。

### 在亮色模式下使用配色方案

如果你愿意为统一配色方案牺牲部分性能与加载速度，你可以按照如下步骤让 Dark Reader 为亮色模式注入额外的 CSS 代码以启用配色方案。

1. 重复[开启配色方案功能](#开启配色方案功能)过程中的第 1 - 2 步以进入 Dark Reader 设置标签页。
2. 通过左侧侧边栏导航到 Automation，将「Automation Behavior」切换为「Toggle Dark / Light」。

需要注意，**亮色模式与暗色模式需要分别手动设置配色方案**。你可以立即在插件选项页切换当前的插件状态并更改配色方案，也可以稍后于需要时再行执行。

### 强制网页始终使用个性化配色方案

Dark Reader 会自动检测网页是否适配了暗色模式，并且在已经适配的情况下不再进行覆盖。如果你希望网页始终使用个性化配色方案，可以按照如下方式操作：

1. 重复[开启配色方案功能](#开启配色方案功能)过程中的第 1 - 2 步以进入 Dark Reader 设置标签页。
2. 通过左侧侧边栏导航到 General，关闭「Detect dark theme」选项。

> [!tip] 希望获得更加贴近配色方案的网页显示效果？
>
> 作者在使用过程中发现，亮色网页在 Dark Reader 的处理下更能贴近配色方案。即使关闭了 Detect dark theme 选项也不会改变这一点。
> 
> 因此，你可以手动将部分支持自动切换主题颜色的网站调整为亮色以获取更好的观感。
